FRANKLYHOTDOGBack to the toy

Take it browsing

Enable Frankly Hotdog for a tab, then hover over a visible image for a moment. Press Escape or use the extension button to pause. Reloading the page turns it off.

Download browser extension

Install in Chrome or Edge

  1. Download and unzip the extension.
  2. Open your browser’s Extensions management page and turn on Developer mode.
  3. Choose Load unpacked and select the folder containing manifest.json.
  4. Open a normal webpage. Click Frankly Hotdog in the toolbar and choose Enable on this tab.

This is a manual installation package, not a Chrome Web Store listing. The OpenAI plugin provides image classification in chat; the extension provides browser hover detection. It supports visible HTML images in the top page, not CSS backgrounds, videos, browser settings pages, or images inside frames.

You control what gets shared

It starts paused on every page. When enabled, hovering for 650 milliseconds sends the selected image for analysis. If direct image access is blocked, it captures the active tab in memory and crops it to the visible image before sending. The full screenshot is never uploaded. Avoid sensitive pages and images covered by other page elements. Partially visible protected images must be scrolled fully into view.
