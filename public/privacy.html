Privacy

Frankly Hotdog is operated by agammann. This policy describes the website, browser extension, and image classification plugin.

What is processed

The service processes the image you select, or a public image URL you provide, only to classify it as HOTDOG, NOT HOTDOG, or UNCERTAIN. Do not provide images containing private information or URLs with access credentials.

The extension operates only after you enable it for the current tab. It can create a temporary tab screenshot when a hovered image cannot be read directly. It crops the screenshot locally to that image. The full screenshot is never uploaded, saved to disk, or passed to the page. The cropped image is sent for classification. Page text, browsing history, and cookies are not sent by the extension.

Recipients and retention

Selected images pass through our hosting service to the OpenAI API. We request that API response storage be disabled. OpenAI may retain data for abuse monitoring under its API data policies. Disabling response storage does not disable those policies.

Our application does not save images or classification results in a database. Images are held in memory during requests. The website and extension cache verdicts in memory for the current page only; reloading clears that cache. The application maintains a daily aggregate request count without image contents or user identifiers. Our rate limiter holds an IP address and a per minute counter in server memory, which are removed after expiry when subsequent traffic triggers cleanup. Hosting and API providers may separately process network and security logs under their own policies.

Your controls

Use Pause or Escape to stop new extension requests. A request already sent may finish. Reload to clear local verdicts. Remove the extension to end its access. The website offers Clear results and Pause hover controls. No advertising or analytics SDKs are included.

Contact

Publisher profile and public support contact: github.com/agammann. Do not post sensitive images or credentials in public support requests.
